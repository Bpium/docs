# Разделы

Перед тем, как знакомиться с каталогами, нужно понять, что такое разделы и как с ними работать.\
\
Разделы помогают наводить порядок: с их помощью вы можете группировать каталоги со связанными по смыслу данными. Количество разделов в Бипиуме не ограничено. Разделы отображаются в верхней части экрана. По умолчанию в системе созданы два раздела — «Новый» и «Управление».

### Создание нового раздела

В конце списка разделов расположена кнопка добавления нового раздела. Создавать разделы могут только сотрудники с правом администрировать раздел «Управление».

Созданные разделы видны всем сотрудникам компании, пока на них не ограничили права.

<figure><img src="../.gitbook/assets/Создание раздела.png" alt=""><figcaption><p>Создание раздела</p></figcaption></figure>

### Настройки раздела

Нажмите на иконку ⚙️ «Настройки раздела» справа от списка со всеми разделами. Откроется меню с действиями:

* Доступ к разделу — назначение прав на раздел для сотрудников и групп
* Переименовать — изменение названия раздела
* Задать ID для API — назначение технического идентификатора для работы через API
* Удалить раздел — удаление раздела вместе со всеми его каталогами и данными

Набор доступных действий зависит от назначенных прав.

<figure><img src="../.gitbook/assets/Настройки раздела.png" alt=""><figcaption><p>Настройки раздела</p></figcaption></figure>

### Удаление раздела

При удалении раздела также удаляются и все каталоги этого раздела. При этом, если другие записи ссылаются на записи удаленных каталогов, то эти связи останутся. Но открыть удаленные связанные записи будет нельзя.

<figure><img src="../.gitbook/assets/Удаление раздела.png" alt=""><figcaption><p>Удаление раздела</p></figcaption></figure>

### Восстановление удаленного раздела

Удаленный раздел и каталоги становятся недоступны через приложение или API. Однако они сохраняются в базе данных, для возможности восстановления в случае ошибочного удаления. Для консультации по восстановлению данных напишите запрос на [support@bpium.ru](mailto:support@bpium.ru).
