Каталог «Процессы» -- это журнал всех запущенных автоматизаций. Здесь можно отслеживать что выполняется прямо сейчас, проверять результаты завершенных процессов и разбирать причины ошибок.

![](<../../../.gitbook/assets/Каталог Процессы.png> "Каталог Процессы")


## Свойства полей записи

{% table header="row" %}

---

*  {% colwidth=[200] %}

   Поле

*  {% colwidth=[582] %}

   Описание

---

*  {% colwidth=[200] %}

   Дата запуска

*  {% colwidth=[582] %}

   Дата и время запуска процесса.

---

*  {% colwidth=[200] %}

   Сценарий

*  {% colwidth=[582] %}

   Ссылка на запись в каталоге «Сценарии» -- какая автоматизация была запущена.

---

*  {% colwidth=[200] %}

   Тип запуска

*  {% colwidth=[582] %}

   **Асинхронный** -- Бипиум запускает процесс в фоне и не возвращает результат инициирующему событию. Используется для уведомлений: отправка письма, обновление связанной записи. Ограничение: 1 сутки (в облаке).

   **Синхронный** -- Бипиум ждёт результата процесса, чтобы вернуть его событию. Используется для запросов: разрешить или запретить операцию, показать сообщение сотруднику. Ограничение: 60 секунд.

---

*  {% colwidth=[200] %}

   Код

*  {% colwidth=[582] %}

   Уникальный идентификатор конкретного запуска процесса.

---

*  {% colwidth=[200] %}

   Событие

*  {% colwidth=[582] %}

   Подписка из каталога «События», которая запустила этот процесс.

---

*  {% colwidth=[200] %}

   Параметры запуска

*  {% colwidth=[582] %}

   Входные данные, переданные сценарию -- контекст записи в момент запуска.

---

*  {% colwidth=[200] %}

   Инициатор

*  {% colwidth=[582] %}

   Сотрудник, действие которого запустило процесс.

---

*  {% colwidth=[200] %}

   Статус

*  {% colwidth=[582] %}

   Текущая стадия или итог выполнения -- см. таблицу статусов ниже.

---

*  {% colwidth=[200] %}

   Дата завершения

*  {% colwidth=[582] %}

   Дата и время завершения процесса.

---

*  {% colwidth=[200] %}

   Результат

*  {% colwidth=[582] %}

   Данные, которые вернул сценарий. При ошибке -- текст с описанием причины сбоя.

---

*  {% colwidth=[200] %}

   Длительность

*  {% colwidth=[582] %}

   Время выполнения процесса в секундах.

{% /table %}
