Каталог «Сценарии» хранит автоматизации Бипиума. Каждая запись -- это один сценарий: описание логики в виде схемы, которую Бипиум выполняет при наступлении события.

## Как сценарий связан с событием

Сам по себе сценарий не запускается -- он привязывается к событию. В каталоге «События» создается подписка, в которой указывается: за каким каталогом следить и какой сценарий запускать при срабатывании. Одному сценарию может соответствовать несколько событий.

Подробнее о настройке подписок читайте в статье [События](./events).

   **Название**

*  {% colwidth=[660] %}

---

*  {% colwidth=[124] %}

   **Описание**

*  {% colwidth=[660] %}

   Произвольный комментарий к сценарию -- для чего он нужен, что делает, где используется.

---

*  {% colwidth=[124] %}

   **Сценарий**

*  {% colwidth=[660] %}

   Файл со схемой автоматизации в формате *\*.bpmn*. Создается и редактируется в визуальном редакторе сценариев -- он открывается при нажатии в поле «Сценарий» на кнопку «Создать».\
   Также можно загрузить готовый сценарий в систему с компьютера или прикрепить по ссылке.

{% /table %}

Готовый файл \*.*bpmn*  можно скачать из карточки и загрузить в другую систему Бипиума -- это удобно для переноса автоматизаций между окружениями.

:::info 

Редактор сценариев -- отдельный инструмент для построения автоматизаций. Подробнее о компонентах, переменных и логике читайте в статье [Автоматизации](./../../processes/_index).

:::
