## Как добавить поле

1. Откройте конструктор каталога — нажмите на иконку шестерёнки рядом с названием каталога.
2. Слева вы увидите список Полей, которые можно добавить в структуру каталога.
3. Выберите тип поля из списка и перетащите его в анкету каталога.
4. Задайте название и настройте свойства в панели справа.
5. Сохраните изменения.

## Действия с полем в конструкторе

### Переименовать

Нажмите на название поля в конструкторе — оно станет редактируемым. Введите новое название и нажмите Enter или кликните в сторону.

<figure><img src="../../../.gitbook/assets/Переименование поля.png" alt=""><figcaption><p>Переименование поля</p></figcaption></figure>

### Сделать обязательным

Нажмите на иконку звёздочки рядом с полем — поле станет обязательным для заполнения. Сотрудник не сможет сохранить запись без заполнения обязательного поля.

<figure><img src="../../../.gitbook/assets/Обязательность заполнения поля.png" alt=""><figcaption><p>Обязательность заполнения поля</p></figcaption></figure>

### Изменить порядок

Захватите поле за иконку слева от названия и перетащите вверх или вниз. Порядок полей в конструкторе соответствует порядку отображения в анкете записи.

<figure><img src="../../../.gitbook/assets/Иконка захвата слева от поля — перетаскивание.png" alt=""><figcaption><p>Иконка захвата слева от поля — перетаскивание</p></figcaption></figure>

### Удалить поле

Нажмите на иконку корзины справа от поля — появится диалог подтверждения. После удаления поле исчезнет из структуры каталога.

<figure><img src="../../../.gitbook/assets/Иконка корзины у поля.png" alt=""><figcaption><p>Иконка корзины у поля</p></figcaption></figure>

### Настройка свойств поля

Панель с настройками позволяет настроить поле под свои нужды. Свойства бывают общие для всех полей (подробнее в [Свойства](../svoistva.md)) и индивидуальные для каждого поля (подробнее в статье каждого поля).&#x20;

<figure><img src="../../../.gitbook/assets/Панель свойств поля — вкладки Свойства, Видимость, Зависимости.png" alt=""><figcaption><p>Панель свойств поля — вкладки Свойства, Видимость, Зависимости</p></figcaption></figure>

Помимо свойств у каждого поля есть две дополнительные вкладки:

* [**Видимость**](../vidimost.md) — позволяет скрывать поле в зависимости от значений других полей
* [**Зависимости**](../zavisimosti.md) — позволяет делать поле обязательным или менять его параметры в зависимости от условий
