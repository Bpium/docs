Текстовое поле, которое заполняется с помощью большой языковой модели (LLM). Сотрудник нажимает кнопку «Сгенерировать» -- ИИ анализирует данные записи и возвращает результат в поле.

## Когда использовать

ИИ-поле подходит для задач, где нужно автоматически сформировать текст на основе данных из других полей записи. Примеры:

-  Склонение ФИО по падежам -- поле «ФИО в дательном падеже» из поля «ФИО»

-  Краткое резюме по заполненным полям клиента или сделки

-  Классификация или тегирование -- определить тип обращения по тексту комментария

-  Перевод текста на другой язык

-  Генерация текста письма или предложения по параметрам записи

## Настройка

В параметрах отображаются элементы поля, которые необходимо настроить.

![](<../../../../.gitbook/assets/Секция Параметры в настройке поля.png> "Секция Параметры в настройке поля")

**Способ ввода.** В настройках поля выберите «ИИ-запрос». Именно этот режим активирует все параметры ниже.

![](<../../../../.gitbook/assets/Способ ввода ИИ-запрос.png> "Способ ввода ИИ-запрос")

**Сервис.** Выберите языковую модель для обращения. Доступные сервисы: `YandexGpt(Бесплатно от Бипиум), YandexGpt, GigaChat, Deepseek, Grok, Sonar(Perplexity)`. ![](<../../../../.gitbook/assets/Выбор языковой модели ИИ.png>)

**Модель.** Укажите конкретную модель выбранного сервиса из списка. Недоступно для «YandexGPT (бесплатно от Бипиум)» -- там модель фиксирована.

![](<../../../../.gitbook/assets/Выбор модели сервиса из списка.png> "Выбор модели сервиса из списка")

**Авторизационный токен.** Каждый сервис использует API ключ (токен) для аутентификации, необходимо его получить на официальном сайте сервиса\*\*.\*\* Укажите API ключ токен для доступа к API сервиса --  выберите из каталога «Доступы к сервисам». Не требуется для YandexGPT (бесплатно от Бипиум).

![](<../../../../.gitbook/assets/Выбор авторизационного токена из выпадающего списка.png> "Выбор авторизационного токена из выпадающего списка")

**Идентификатор каталога Yandex Cloud (для Сервиса YandexGPT).** Позволяет указать идентификатор каталога Yandex Cloud через переменную или выбрать из списка уже добавленных в каталог Доступы к сервисам.

![](<../../../../.gitbook/assets/Выбор идентификатора каталога Yandex Cloud.png> "Выбор идентификатора каталога Yandex Cloud")

**Промпт.** Напишите инструкцию для модели -- что именно нужно сделать с данными записи. Чем точнее промпт, тем предсказуемее результат.

![](../../../../.gitbook/assets/Промпт..png "Промпт.")

## Как написать хороший промпт

Промпт -- это инструкция для модели. Несколько советов:

-  **Опишите задачу конкретно.** «Переведи поле Описание на английский язык» лучше, чем «Переведи».

-  **Укажите формат результата.** Например: «Ответь одним предложением», «Верни только список через запятую», «Используй официальный стиль».

-  **Не нужно перечислять поля**. Модель получает все данные записи автоматически -- просто опишите что нужно сделать.

## Как работает поле для сотрудника

После того как администратор настроил ИИ-поле, в анкете записи появляется кнопка «Сгенерировать». Сотрудник нажимает её -- система отправляет данные записи в выбранную модель и записывает результат в поле. Генерация занимает несколько секунд.

Результат можно отредактировать вручную после генерации -- поле остаётся обычным текстовым.

![](<../../../../.gitbook/assets/Кнопка сгенерировать для запуска работы ИИ-поля.png> "Кнопка сгенерировать для запуска работы ИИ-поля")

При нажатии произойдёт генерация ФИО в дательном падеже.
