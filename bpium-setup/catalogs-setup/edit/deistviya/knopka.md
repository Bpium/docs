Поле для запуска автоматизаций непосредственно из карточки записи.

![](<../../../../.gitbook/assets/Поле типа Кнопка.png> "Поле типа Кнопка")

Поле типа Кнопка позволяет запускать автоматизации без сохранения записи. В одном поле можно разместить несколько кнопок для выполнения различных действий.

### Когда использовать

Используйте поле Кнопка, когда сотруднику необходимо вручную инициировать выполнение действия. Типичные примеры:

- Формирование договора или счёта
- Отправка письма или уведомления
- Согласование или отклонение заявки
- Заполнение полей записи по заданным условиям
- Получение данных из внешней системы

### Настройка

В конструкторе каталога нажмите «изменить» у поля Кнопка. Добавьте одну или несколько кнопок.

Для каждой кнопки можно указать:

- **Название** -- текст, отображаемый на кнопке.
- **Цвет** -- цвет кнопки.
- **Иконка** -- значок, отображаемый рядом с названием.
- **ID** -- идентификатор кнопки, по которому можно определить, какая кнопка была нажата.

Порядок кнопок можно менять перетаскиванием.

### Настройка события

Для выполнения сценария по нажатию кнопки создайте подписку в каталоге «События»:

1. В поле «Каталог» выберите каталог, в котором находится кнопка.
2. В поле «События» выберите «Изменено поле во время редактирования».
3. В поле «Отслеживать поля» укажите ID поля типа Кнопка.
4. В поле «Выполнить» укажите запуск процесса по нужному сценарию.
5. Установите статус «Активно» и сохраните запись.

Подробнее о настройке подписок -- в статье «События».

:::lab

**Примечание**\
Кнопка неактивна, если для поля не настроено событие или вебхук типа «Изменено поле во время редактирования». Во время обработки события кнопки временно блокируются.

:::

### Использование в сценариях

При нажатии кнопки в объектах `values` и `allValues` передаётся ID нажатой кнопки.

Например, если ID поля -- `12`, а ID кнопки -- `approve`,  выражения `values['12']` и `allValues['12']` вернут `"approve"`.

Если в одном поле размещено несколько кнопок, используйте их идентификаторы для ветвления сценария.

После обработки события значение поля сбрасывается, что позволяет повторно нажать кнопку.
