Кнопка для выполнения действий над записью -- отправка, обновление, запуск процесса или внешний вызов.

![](<../../../../.gitbook/assets/Поле типа Кнопка.png> "Поле типа Кнопка")

Кнопка для инициации события. Кнопка становится активной при создании события типа «Изменено поле во время редактирования», отслеживающее изменение в поле, в котором находится кнопка. Не имеет параметров.
