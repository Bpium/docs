Коммуникации -- это компоненты процессов, предназначенные для взаимодействия с внешними системами и пользователями.

# Коммуникации

С помощью коммуникаций процессы могут отправлять и получать данные, инициировать внешние действия и реагировать на события вне системы.

Коммуникации используются для интеграций, уведомлений и обмена данными.
