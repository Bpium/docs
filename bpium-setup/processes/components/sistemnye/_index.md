order: 1
---

Системные компоненты управляют ходом выполнения сценария: запускают и останавливают процесс, управляют временем, обрабатывают ошибки и ветвят логику.

### Список компонентов

| Компонент | Назначение |
|---|---|
| [Начало процесса](nachalo-processa.md) | Стартовое событие, с которого начинается сценарий |
| [Конец процесса](konec-processa.md) | Завершает выполнение сценария и передаёт результаты |
| [Таймер](taimer.md) | Приостанавливает выполнение на заданное время или служит пограничным событием для таймаута |
| [Ошибка](oshibka.md) | Пограничное событие для обработки ошибок компонентов |
| [Шлюз «ИЛИ» (условное ветвление)](shlyuz-ili-uslovnoe-vetvlenie.md) | Ветвление процесса по условиям или синхронизация нескольких потоков |
