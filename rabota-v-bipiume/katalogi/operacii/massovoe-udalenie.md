Позволяет быстро удалить все записи каталога или большое количество отобранных записей -- без необходимости удалять каждую по отдельности.

Массово удалить записи поможет в следующих случаях:

-  Нужно удалить все записи каталога

-  Нужно удалить отобранные записи каталоге, не прибегая к ручному удалению каждой записи отдельно

## Удаление всех записей каталога

Используйте этот способ когда нужно полностью очистить каталог -- например, после заполнения тестовыми данными при разработке.

1. Убедитесь, что в каталоге выбран вид **«Все записи»** и сброшены все фильтры -- иначе удалятся только отфильтрованные записи, а не все.

   ![](<../../../.gitbook/assets/Каталог в виде «Все записи» без активных фильтров.png> "Каталог в виде «Все записи» без активных фильтров")

   

2. Нажмите на стрелку рядом с кнопкой «Создать» и выберите «Удалить n записей».

   ![](<../../../.gitbook/assets/Кнопка удалить все записи.png> "Кнопка «Удалить n записей».")

   

3. В открывшемся окне нажмите «Удалить записи».

   ![](<../../../.gitbook/assets/диалог подтверждения удаления с кнопкой «Удалить записи».png> "Диалог подтверждения удаления с кнопкой «Удалить записи»")

4. Бипиум начнёт удаление. Дождитесь завершения процесса.

![](<../../../.gitbook/assets/Процесс удаления - индикатор процесса.png> "Процесс удаления — индикатор процесса.")

![](<../../../.gitbook/assets/Пустой каталог после массового удаления записей..png> "Пустой каталог после массового удаления записей.")



## Удаление отобранных записей

Используйте этот способ когда нужно удалить не все записи, а только определённую выборку.

1. Настройте фильтры чтобы в каталоге отображались только те записи, которые нужно удалить.

![](<../../../.gitbook/assets/Каталог с применённым фильтром -- видны только нужные для удаления записи.png> "Каталог с применённым фильтром -- видны только нужные для удаления записи.")



1. Нажмите на стрелку рядом с кнопкой «Создать» и выберите «Удалить n записей».

2. В открывшемся окне нажмите «Удалить записи».

3. Дождитесь завершения процесса.

:::note 

После нажатия «Удалить записи» процесс начнётся немедленно. Уже удалённые записи восстановить вручную невозможно. Процесс можно прервать -- но только те записи которые ещё не были удалены к этому моменту останутся нетронутыми.

:::
