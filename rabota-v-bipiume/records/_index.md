Запись -- это единица данных в каталоге. Если каталог -- это таблица, то запись -- одна строка в ней. Нажмите на строку в каталоге -- откроется карточка записи.

![](<../../.gitbook/assets/каталог -- выделена строка, которую нужно нажать чтобы открыть запись (1).png> "Выделена строка, которую нужно нажать чтобы открыть запись")

![](<../../.gitbook/assets/открытая карточка записи (1).png> "Открытая карточка записи")

## Структура Записи

Карточка записи состоит из нескольких элементов

-  **Вкладки.** Каждая вкладка может содержать в себе секции  и поля для

![](<../../.gitbook/assets/Открыиая карточка записи с выделенными вкладками.png> "Открытая карточка записи с выделенными вкладками")

-  **Секции.** Секции позволяют группировать поля записи по функциональным блокам. Секции при необходимости можно скрыть.

![](<../../.gitbook/assets/Открытая карточка записи с выделенными секциями.png> "Открытая карточка записи с выделенными секциями")

-  **Поля.** Элементы для ввода и хранения данных внутри секций.

## Режимы открытия записи

Запись можно открыть двумя способами:

-  **Сбоку** -- карточка открывается в панели справа от списка записей. Список остаётся видимым, можно переключаться между записями не закрывая карточку.

![](<../../.gitbook/assets/Карточка открыта сбоку -- список записей слева, карточка справа.png> "Карточка открыта сбоку -- список записей слева, карточка справа")

-  **В отдельном окне** -- карточка открывается на весь экран. Удобно для детальной работы с записью у которой много полей.

![](<../../.gitbook/assets/Кнопка открытия записи в полноэкранном окне.png> "Кнопка открытия записи в полноэкранном окне")

![](<../../.gitbook/assets/Карточка открыта в отдельном полноэкранном окне.png> "Карточка открыта в отдельном полноэкранном окне")

### Дерево записей

Когда вы открываете связанную запись прямо из карточки другой записи -- появляется дерево записей. Оно показывает на каком уровне вложенности вы сейчас находитесь и помогает не потеряться при работе с цепочкой связанных записей.

Например: вы открыли сделку, из неё открыли карточку клиента, из клиента -- карточку контактного лица. Дерево покажет всю эту цепочку и позволит быстро вернуться на любой уровень.



![](<../../.gitbook/assets/Дерево записей.png> "Дерево записей")

Дерево записей видно при открытии карточки в полноэкранном режиме, при просмотре связанной записи и при создании новой записи в связанном поле.
